## **Cordura y Pérdida de SAN**

Los Agentes de Delta Green son tan vulnerables al **trauma mental** como a las amenazas físicas. Esa vulnerabilidad se rastrea mediante **Puntos de Cordura (SAN)**. Cuando la SAN cae bruscamente, el Agente pierde **autocontrol** y el jugador pierde **control sobre el Agente**.

## **Amenazas a la Cordura**

Existen tres tipos de pérdida de SAN:

1. **Violencia** (tanto al sufrirla como al infligirla)
    
2. **Impotencia (Helplessness)**
    
3. **Lo Sobrenatural (Unnatural)**
    

Cada amenaza viene con **dos posibles pérdidas de SAN**, una menor y otra mayor.

- Cuando el Agente enfrenta una amenaza, realiza una **tirada de SAN**:
    
    - Tirar **por debajo o igual a la SAN actual** en dados percentiles.
        
    - **Éxito:** el Agente sufre la pérdida menor.
        
    - **Éxito crítico:** el Agente sufre la pérdida mínima posible.
        
    - **Fracaso:** el Agente sufre la pérdida mayor.
        
    - **Fracaso crítico:** el Agente pierde la pérdida máxima posible.
        

---

### **Pérdida por Sufrir Violencia**

| Situación                                | SAN menor / SAN mayor |
| ---------------------------------------- | --------------------- |
| Emboscado o alcanzado por disparos       | 0 / 1                 |
| Sorprendido por un cadáver               | 0 / 1                 |
| —Cadáver de alguien querido              | 0 / 1D4               |
| Apunalado o estrangulado inesperadamente | 0 / 1D4               |
| Reducido a 2 HP o menos                  | 0 / 1D6               |
| Torturado                                | 0 / 1D10              |

---

### **Pérdida por Infligir Violencia**

|Situación|SAN menor / SAN mayor|
|---|---|
|Incapacitar o mutilar a un inocente|0 / 1D4|
|Destruir el cuerpo de un compañero para impedir investigación*|0 / 1D4|
|Matar en defensa propia*|0 / 1D4|
|Matar a un enemigo asesino a sangre fría*|0 / 1D6|
|Torturar a alguien|0 / 1D8|
|Matar accidentalmente a un inocente*|0 / 1D8|
|Matar a un inocente a sangre fría, incluso por una buena razón*|1 / 1D10|

*Para una tirada fallida, suma 1 por víctima hasta el máximo del dado: 4 para 1D4, 6 para 1D6, etc.

---

### **Pérdida por Impotencia (Helplessness)**

|Situación|SAN menor / SAN mayor|
|---|---|
|Despedido del trabajo|0 / 1|
|Un amigo sufre daño permanente o locura indefinida|0 / 1|
|La puntuación de un Bond llega a cero|0 / 1D4|
|Sentenciado a prisión|0 / 1D4|
|Despertar paralizado o ciego|0 / 1D4|
|Encontrar los restos de un amigo|0 / 1D4|
|Arrojado a un pozo de cadáveres|0 / 1D4|
|Un Bond sufre daño permanente o locura indefinida|1 / 1D4|
|Ver o escuchar a un amigo ser asesinado brutalmente|0 / 1D6|
|Un Bond muere|1 / 1D6|
|Ver o escuchar a un Bond ser asesinado brutalmente|1 / 1D8|

---

### **Pérdida por Lo Sobrenatural (Unnatural)**

|Situación|SAN menor / SAN mayor|
|---|---|
|Intentar psicoterapia en alguien que perdió SAN por lo sobrenatural|0 / 1|
|Presenciar un efecto sobrenatural aparentemente benigno|0 / 1|
|Presenciar un efecto sobrenatural violento|0 / 1D6|
|Ver a un cadáver caminar|0 / 1D6|
|Ser sujeto a un efecto sobrenatural evidente|0 / 1D6|
|Sufrir un ataque sobrenatural violento|1 / 1D8 o más|
